# 计算机协会招新答题题库（小白友好版）

> 供「计算机协会招新答题系统」后台「题库 → 批量导入」直接使用。
> 全部为四选一单选题，面向**零基础同学（小白）**：以日常电脑/手机使用常识为主，看题即会，不考公式、不考专业术语。
> 文件均为 UTF-8 带 BOM 的 CSV，Excel / WPS 可直接打开，也可直接上传导入。

## 一、文件清单

| 文件 | 定位 | 题量 | 内容方向 |
|---|---|---|---|
| `一级-计算机基础及MS-Office应用.csv` | 纯小白基础 | 60 | 开关机、鼠标键盘、桌面文件、常用软件、网络/安全常识 |
| `二级-公共基础知识.csv` | 入门常识进阶 | 40 | 容量单位、二进制、软硬件、网络与安全、AI/大数据等常识 |
| `二级-Python语言程序设计.csv` | 编程入门 | 30 | 最基础的 print/变量/类型/列表/循环/函数 |
| `二级-MS-Office高级应用.csv` | 办公操作入门 | 20 | Word/Excel/PPT 的常用操作与快捷键 |

合计 150 题。

## 二、CSV 格式（与系统导入模板一致）

| 列 | 含义 | 说明 |
|---|---|---|
| 1 | 题目 | 题干文本；以「示例」开头的行会被自动跳过 |
| 2–7 | 选项 A–F | 本题库均为 A–D 四项，E/F 留空 |
| 8 | 正确答案 | `A`–`D` 单个字母（大小写均可），已与选项列严格对应 |
| 9 | 难度 | `容易` / `简单` / `困难` 三者之一 |
| 10 | 分值 | 正整数，本题库统一为 10 |

- 首行为表头（第一列含「题目」），导入时自动跳过。
- 选项展示时系统会按用户乱序，因此「正确答案」字母只与文件内选项列对应，不影响答题公平（本题库已校验通过）。

## 四、导入步骤

1. 访问 `/admin`，输入后台口令进入。
2. 进入「题库」标签页，点「批量导入」，逐个选择上面的 `.csv` 文件上传。
3. 导入完成后在题库列表核对题量与「启用」状态。

## 五、关于「一级 / 二级」区分的说明（重要）

当前系统题库表 `questions` 只有 `difficulty`（容易/简单/困难）一个筛选维度，**没有「等级/科目」字段**；答题抽题也只按难度过滤。因此：

- 直接混合导入后，抽题按难度混合出现，无法按「一级/二级」区分组卷。
- 本题库采用「分文件」组织，方便按场次选择性导入（例如招新赛只导一级文件，进阶赛再导二级文件）。

如需在系统内真正区分一级/二级组卷，建议后续给题库增加 `level`（或 `category`）字段并在抽题/后台增加筛选，可另立任务实现；在未改造前，用「分文件、分批次导入」的方式临时隔离。
